# Mehul Mahrishi Academic Website — V5

Cloudflare Pages + GitHub free-hosting edition.

## What changed from V4
- Removed Netlify dependency
- Cloudflare Pages `_headers` and `_redirects`
- $0-hosting contact approach using a structured email composer
- GitHub Actions link validation
- Domain finalization script for canonical URLs, sitemap and robots.txt
- Cloudflare-specific deployment guide
- Domain launch checklist
- Existing researcher-first design, publication pages and project/research pages retained

## Start here
